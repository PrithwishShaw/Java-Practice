OOP (Object Oriented Programming)

key features:-
1. Structural code into logical units (Classes and objects)
2. keeps related data and methods together (Encapsulation)
3. Make code modular, reusable and scalable.
4. Prevent unauthorised access to data.
5. Follow the DRA (Don't Repeat Yourself) principle.

OPP advantage over procedural language:-
1. It is faster and easier to execute.
2. It provides a clear structure to the program.
3. It helps to keep the Java code DRY and make the code easier to maintain, modify and debug.
4. It makes it possible to create full reusable applications with less code and shorter development time.
